This repository contains tools and scripts I’ve created as part of my learning journey as an apprentice software developer.

## 📌 Current Projects

### 🔹 Meme Coin Volume & Price Tracker
A Python script that:
- Monitors real-time price and 24h volume of select meme coins using the **CoinGecko API**
- Tracks buy/sell pressure on Solana-based coins using the **Bitquery (Moonshot) API**
- Alerts based on price and volume spikes to help spot potential pumps

💡 Logs data to `crypto_tracker.log`  
🔐 API keys are excluded using `.gitignore`  
🛠 Easily extendable to track multiple coins
